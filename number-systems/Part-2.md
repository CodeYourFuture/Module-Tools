Q16: How can you test if a binary number is a power of two (e.g. 1, 2, 4, 8, 16, ...)?
Answer:binary number is a power of two if it has exactly one 1 bit and the other bits are 0. If it has more 1s (eg 10100) then it is not to the power of two

Q17: If reading the byte 0x21 as an ASCII character, what character would it mean?
Answer:ASCII is American Standard Code . It is a 7-bit character code where each individual bit represents a unique character. and hexadecimal 21 represents the symbol !

Q19: If reading the bytes 0xAA00FF as a sequence of three one-byte decimal numbers, what decimal numbers would they be?
Answer:So the three decimal numbers are: 170, 0, 255

Q20: If reading the bytes 0xAA00FF as an RGB colour, as described in "Approaches for Representing Colors and Images", what colour would it mean?
Answer: An RGB colour uses three bytes: AA = Red value = 170 , 00 = Green value = 0, FF = Blue value = 255a bright purple colour
